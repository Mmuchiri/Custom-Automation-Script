This Bash script automates system file organization and timestamped backup creation. Upon execution, it prompts the user for confirmation (⁠y/n⁠) before running. It then scans the user's ⁠~/Downloads⁠ directory for ⁠.txt⁠ files using a ⁠for⁠ loop and automatically moves them to ⁠~/Documents/TextFiles⁠. After organizing the files, the script archives the ⁠TextFiles⁠ directory into a timestamped compressed backup file (⁠.tar.gz⁠) stored inside ⁠~/Backups⁠. Every action, date, and execution status is recorded in ⁠/home/$USER/script_log.txt⁠.
